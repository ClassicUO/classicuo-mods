# classicuo-mods

Mod registry for [ClassicUO](https://github.com/ClassicUO/ClassicUO) WASM mods.
Think crates.io, minus the server: the registry is this git repo, the artifacts
are GitHub Releases, and publishing is a pull request.

- `mods/<name>.json` — one entry per mod (the index).
- `index.json` — all entries merged; regenerated by CI on every push to `main`.
  Clients fetch `https://raw.githubusercontent.com/ClassicUO/classicuo-mods/main/index.json`.

## Publish a mod

1. Build your mod (`make build-mods`) and zip the mod folder contents:
   the zip root must contain `mod.json` and the `mod.wasm` it names.
2. Upload the zip to a GitHub Release on **your own** repository.
3. Add or bump `mods/<name>.json` here and open a PR:

```json
{
  "name": "ecs-status",
  "version": "1.2.0",
  "abi": "2",
  "description": "Status bar replacement",
  "authors": ["your-github-login"],
  "repository": "https://github.com/you/ecs-status",
  "license": "MIT",
  "download": "https://github.com/you/ecs-status/releases/download/v1.2.0/ecs-status.zip",
  "sha256": "<sha256 of the zip>"
}
```

CI downloads the zip and checks: sha256 matches, zip contains `mod.json` +
the named wasm, the wasm is a core module (not a Component Model binary),
`mod.json` name/version equal the registry entry, version is greater than the
previous one, and — on updates — the PR author is listed in the existing
`authors`. Merge = live.

Run the same check locally: `python3 scripts/validate.py mods/<name>.json`.
